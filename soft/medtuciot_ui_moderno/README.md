# MedTuCIoT - UI/UX moderna

Proyecto estático listo para GitHub Pages o hosting simple.

## Incluye
- UI moderna y minimalista
- Sidebar colapsable al hacer clic en el logo
- Lucide Icons gratis
- Campana de notificaciones
- Cambio de foto de perfil al hacer clic
- Panel cliente con selectores de lugar y dispositivo
- Envío de notificaciones a todos / uno / varios clientes
- Tema oscuro/claro
- PWA base
- Integración preparada para Supabase

## Configuración
Editar `assets/js/config.js` con:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

## Rutas
- `#/login`
- `#/admin/dashboard`
- `#/admin/devices`
- `#/admin/notificaciones`
- `#/admin/perfil`
- `#/cliente/dashboard`
